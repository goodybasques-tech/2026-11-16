# 数据合同

所有 AI 和脚本之间只靠这几个文件交接。格式定义在 `contracts/*.schema.json`。不管是谁（人、Gemini、ChatGPT、Claude、GPT）、改了什么，交出去之前都要跑一遍 `python3 tools/validate.py episodes/<本期>`，有错误就不能进下一步。

| 文件 | 谁写 | 谁读 | 能不能手改 |
|---|---|---|---|
| `01_script.json` | Gemini（人审批） | 全部环节 | 可以，改完重跑配音和时间轴 |
| `02_audio/<段>.mp3 + .json` | `tools/tts.py` | `timeline.py` / `voice_track.py` | 不能 |
| `03_timeline.json` | `tools/timeline.py` | 分镜、制作、校验 | 不能（自动生成） |
| `04_assets/manifest.json` + `raw/` | ChatGPT 找图 + 预处理脚本 | 分镜、制作、校验 | 可以（人抽查时改 status） |
| `05_storyboard.json` | Claude（人审批） | 制作、校验 | 可以 |
| `06_scenes/<beat>.js` | Claude（只给 template=custom 的片段） | 渲染 | — |
| `07_review/` | 校验脚本 + GPT | Claude 修复 | — |

## 1. 编号规则

- 章节 `c01`，段落 `p001`，句子 `s0001`（全期唯一、连续编号），图片 `img001`，画面片段 `b001`。
- 句子里的重点词 `e1, e2…`，上屏文字 `o1, o2…`，都是句内编号，对外写成 `s0012.e1`、`s0012.o2`。
- **编号一旦给出就不再变**。改稿时删句保留空号，加句用新号（例如 s0012 后插一句叫 s0101）。分镜、图片都靠编号挂在句子上，重新编号会让下游全部错位。

## 2. 稿子（script）的三条要求

1. `text` 一字不差地送进 TTS。想让配音读成什么样，就写成什么样。
2. `emphasis.text` 必须在原文里逐字出现。画面重音会卡在这个词开口的时刻。
3. 画面上出现的数字、人名、引语、标题，**只能来自 `onscreen`**。制作环节不许重新打字，这是防止上屏信息出错的核心规则。

## 3. 时间锚点（分镜里所有时间都写锚点，不写秒数）

| 写法 | 含义 |
|---|---|
| `START` / `END` | 全片开头 / 结尾 |
| `s0012` / `s0012:end` | 第 12 句第一个词开口 / 最后一个词结束 |
| `s0012.e1` / `s0012.e1:end` | 第 12 句重点词 e1 开口 / 说完 |
| `s0012.w3` / `s0012.w3:end` | 第 12 句第 3 个词开口 / 说完（英文按词，中文按字） |
| `c02` / `c02:end` | 第 2 章开始 / 结束 |
| 任意锚点 + 偏移 | `s0012.e1-0.1`、`s0012:end+0.25`（秒） |

为什么用锚点：改一段稿、重配一段音，只有那一段的秒数会变。分镜挂在句子和词上，会自动跟着走，不用重做画面。

## 4. 上屏文字和素材的引用

- `"@s0012.o1"`：引用稿子里的上屏文字。
- `"#img003"`：引用已批准的图片。
- `"ui:BREAKING"`：频道固定界面字（栏目名、"BREAKING"、章节编号之类），不是新闻信息。
- `title / caption / quote / speaker / label / value / text …` 这些键里出现手打文字，校验直接报错。

## 5. 时间轴（timeline）里有什么

- `sentences / words`：每句、每个词的起止（全片绝对秒）。
- `emphasis`：每个重点词的起止。
- `pauses`：所有 ≥ 0.22s 的停顿，分为句内、句间、段间三类。
- `cut_candidates`：推荐切点（停顿中点），`strength` 1–4。4 = 章节交界，3 = 段间或句间长停顿，1–2 = 句内短停顿。

## 6. 校验器现在检查什么

- 每个文件是否符合格式。
- 稿子：编号不重复；重点词逐字出现；出处存在；需要配图的句子写了找图说明。
- 时间轴：每句都有时间，并且和稿子对得上（稿子改过但没重配会报错）。
- 图片：挂的句子存在；授权不明的图不能批准；有人脸的图必须写人名（供 GPT 查"配错人"）；需要配图的句子有没有已批准的图。
- 分镜：
  - 模板和必填参数都存在；转场在频道列表里。
  - 上屏文字和素材的引用都有效；没有手打文字。
  - 锚点都能解析；片段顺序正确、覆盖全片。
  - 单个片段 < 1.5s 警告，> 9s 警告，> 14s 报错。
  - 切点落在某个词的发音中间时警告。
  - 每个重点词都有对应的画面重音（hits）。
